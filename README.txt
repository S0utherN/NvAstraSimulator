增像管天文模拟器 · 离线便携版 0.4.1（目镜 GPU 版）

打开方式
  1. 先把整个压缩包解压到一个文件夹（不要在压缩软件里直接双击运行）。
  2. 用 Chrome 或 Edge 打开 START.html。无需安装、无需联网、无需启动服务器。
  3. 首次打开会读取内置数据并“开管”，约几秒钟；切换到其他目标时再载入该目标的数据。

需要
  支持 WebGL2 浮点渲染的浏览器（近几年的 Chrome / Edge 桌面版均可）。
  若提示“不支持 WebGL2 / 浮点渲染”，请更新浏览器或显卡驱动；
  笔记本可在系统显卡设置中让浏览器使用独立显卡，放大观察时更流畅。

操作
  拖动画面平移，滚轮放大（在视野内重新计算，不是放大图片），双击复位。
  各参数旁的 ? 有说明；“目标 ?”里列出当前目标的数据来源、定标与缺口。
  START.html?verify 可在本机显卡上运行统计验收（约半分钟）。

0.4.1 修订（按实测观感与论文）
  EBI：暗计数改为“阴极暗发射”，默认 1500 /s·mm²（三代 EBI 约 1×10⁻⁷ lx，与论文实测一致），
    暗电子同样经过离子阻挡膜和 MCP 入口；EBI 同时显示 lx 与 lm/cm²。
  噪声：MCP 探测效率（默认 85%）、MCP 输入增强膜开关、三代离子阻挡膜（无/薄/标准）与阴极电压；
    实际 F² 随 MCP 增益和阴极电压变大；参数纸显示噪声因子 N_f，SNR = 1.03·√(S/N_f)。
  实际信噪比：按画面中心的真实速率显示分辨单元与 0.2 mm 光斑的 SNR，以及天光/暗发射各占多少。
  闪烁亮点（雪花）：离子反馈等偶发亮点，比普通闪点亮且更大。
  人眼感知（显示菜单，默认开）：按荧光屏实际亮度模拟暗视觉的分辨极限，只影响显示。
  大气：星点随气流抖动和闪烁；气溶胶放大光污染（SQM 滑块为晴朗值，旁边显示实际值）。
  反射镜：中心遮挡造成的衍射对比度下降进入画面。
  荧光屏：按实测光效 P22 18.85 / P43 13.2 / P45 7.8 lm/W 计算亮度增益。
  光晕：整个圆盘亮度均匀。MTF5 范围 20–120 lp/mm，宽核权重 0–0.6。
  二代（多碱）阴极曲线在 930 nm 截止（原为 1000 nm）。

0.4.0 新增
  管子：光晕（尺寸与占比）、管温（按阴极类型改变暗计数/EBI）、国产三代阴极预设；
    阴极曲线可切换 mA/W 与 QE（默认 mA/W）。
  物镜：折射 / 反射（透过率，或反射率与中心遮挡）、像差弥散；MTF 曲线显示管、物镜+视宁度与系统。
  大气：消光（Paranal 基线 + 可调气溶胶）、视宁度、目标高度角、气辉强度。
  等效参数纸：各滑块下方显示换算出的参数纸数值；右侧底部有完整参数表（A/B 两列，附 L3 样例对照）。
  观察积分默认改为“实时”。

0.3.1 新增
  A|B 对比：工具栏打开后画面左右分成两半同时实时模拟，面板顶部切换“编辑 A / 编辑 B”，
    拖动中间的分界线调整比例；两侧用同一随机序列，参数相同时画面完全一致。
  阴极响应曲线可直接在图上按住拖动改形，“整体倍率”等比例缩放，“重置曲线”恢复预设。
  工具栏“显示”：观察积分时间、显示对比 γ、保存截图 PNG（含参数说明）、复制当前链接。
  当前参数（含 A/B 与编辑过的曲线）自动记在地址栏 # 之后，收藏该地址即可复现。
  暂停时的静帧按“观察积分时间”曝光，观感与实时画面一致。
