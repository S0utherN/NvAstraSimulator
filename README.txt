增像管天文模拟器 · 离线便携版 0.3.0（目镜 GPU 版）

打开方式
  1. 先把整个压缩包解压到一个文件夹（不要在压缩软件里直接双击运行）。
  2. 用 Chrome 或 Edge 打开 START.html。无需安装、无需联网、无需启动服务器。
  3. 首次打开会读取内置数据并“开管”，约几秒钟；切换到其他目标时再载入该目标的数据。

需要
  支持 WebGL2 浮点渲染的浏览器（近几年的 Chrome / Edge 桌面版均可）。
  若提示“不支持 WebGL2 / 浮点渲染”，请更新浏览器或显卡驱动；
  笔记本可在系统显卡设置中让浏览器使用独立显卡，放大观察时更流畅。

操作
  拖动画面平移，滚轮放大（在视野内重新计算，不是放大图片），双击复位。
  各参数旁的 ? 有说明；“目标 ?”里列出当前目标的数据来源、定标与缺口。
  START.html?verify 可在本机显卡上运行统计验收（约半分钟）。
