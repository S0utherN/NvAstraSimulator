增像管天文模拟器 · 离线便携版 0.5.5（目镜 GPU 版）

打开方式
  1. 先把整个压缩包解压到一个文件夹（不要在压缩软件里直接双击运行）。
  2. 用 Chrome 或 Edge 打开 START.html。无需安装、无需联网、无需启动服务器。
  3. 首次打开会读取内置数据并“开管”，约几秒钟；切换到其他目标时再载入该目标的数据。

需要
  支持 WebGL2 浮点渲染的浏览器（近几年的 Chrome / Edge 桌面版均可）。
  若提示“不支持 WebGL2 / 浮点渲染”，请更新浏览器或显卡驱动；
  笔记本可在系统显卡设置中让浏览器使用独立显卡，放大观察时更流畅。
  手机浏览器同样需要 WebGL2 浮点渲染；卡顿时在“更多 → 画质”选“自动”或“省电”。

操作
  未放大时拖动画面转动望远镜（环顾大场景），放大后拖动平移；滚轮或双指缩放（在视野内重新计算，不是放大图片），双击复位放大。
  各参数旁的 ? 有说明；“目标 ?”里列出当前目标的数据来源、定标与缺口。每个板块底部的“高级设置”展开更多参数。
  START.html?verify 可在本机显卡上运行统计验收（约半分钟）。

0.5.5 修复（手机拖动卡顿，1× 与高倍）
  1× 拖动（转动望远镜）只更新指向，不再每帧重算点扩散核、重新上传光晕核，面板也不再跟着重绘；
  拖动期间星云速率图用较粗的子采样、暂不重新分布光晕（约 5% 的光，总量不变），停手 0.25 s 后按完整精度重算一次；
  光晕在更粗的网格上卷积（光晕是均匀圆盘，精度检查不变）；每帧的计算只覆盖视野及必要的边缘带；
  “自动”画质下放大时网格不细于 5 µm（约为荧光屏光斑核心大小），8× 时每帧工作量约减半。“高”画质不受限制。

0.5.4 修复
  手机上拖动画面的迟滞（0.5.3 引入）：画面信息（信噪比、人眼模糊、高光压缩水平）在拖动或调参时最多每 150 ms
    重算一次，取样点减少；拖动按每帧一次提交；触屏设备的计算网格默认降回与 0.5.2 相当的密度（“更多 → 画质”可选“高”）。
  入口：START.html 与 index.html 内容相同，用网页服务器打开时直接访问文件夹即可。

0.5.3 调整
  新目标：M8 礁湖星云（SHASSA + VPHAS+ 两层，同船底座做法）、M16 鹰状星云（NSNS 两层 + VPHAS+ 1° 核心层）；
    “银心 · 蛇夫座调色盘”改名为“银心”。
  高光自动压缩（“更多”里，默认开，只影响显示）：半白以下原样显示，更亮处用对数肩部压缩，
    视野里最亮的星云落在九成白；M42、船底座、M8 这类大光比目标不再过曝，暗处完全不变。
  显示亮度默认 +1 EV（原 +2）；旧链接仍按 +2 EV、不压缩打开。
  口径：直焦焦比最快 f/1.2，口径不设上限（2000 mm 可到 f/1.2，1667 mm 口径）。
  画面：角落显示天空 SQM 与估算的波特尔等级、实际信噪比；显眼的“拖动画面转动望远镜”提示（拖动一次后隐藏）；
    切换目标时画面中央显示“正在载入”。手机上画面铺满屏宽（细边框）。
  “对比度拖尾”改为“锐利度”（百分比，越高越锐），放在分辨率下面。

0.5.2 调整
  新目标：M31 仙女座星系（深空）。星系本体用 NSNS 的可见光连续谱（已去星，按 550 nm 换算，积分 V = 3.32，
    RC3 总星等 3.44），光谱按 RC3 色指数取 4943 K 黑体；Hα/[O III]/[S II] 扣除了巡天残留的连续谱。
    M32 在巡天里被当作恒星扣掉，按模型补回（总星等 8.08，形状为假设）；核心约 40″ 在巡天里饱和截平。
  手机：上下滑动页面时不会再误调滑块；按一下也不改值，只有明显横向拖动才调整，而且从按下处相对移动，不跳值。
  “倍增噪声 F²”移到外面；雪花亮点频率上限 200 /s·cm²（原 100），默认 20（原 5），亮度默认 ×40（原 ×30）。
    旧链接里没写这两项的，仍按原默认值打开。

0.5.1 调整（界面与性能）
  菜单：每个板块只留常用参数，其余收进“高级设置”；大气与夜空合为一个板块；噪声、增益与分辨率合为一个板块；
    工具栏只留暂停、观察积分、放大和帧率，显示亮度、适配、γ、人眼感知、均值、A|B 对比、截图与链接在“更多”里。
  滤镜：新增前置 / 后置开关（1× 镜头默认前置，望远镜默认后置），后置按焦比的会聚光锥计算通带偏移。
  观察积分默认改回 50 ms；删去阴极“整体倍率”滑块。名称和说明改得更通俗，细节放在说明的第二段。
  “实际信噪比”改为两格读数，并用色条显示背景里天光与管子暗噪声的比例。
  修复：? 说明弹窗不再被面板遮挡或超出屏幕；手机上改为底部弹出。
  手机：画面固定在顶部，下面按“观测 / 增像管 / 参数纸”分页；阴极曲线点“编辑曲线”打开大图编辑，
    “推拉”方式按住上下拖动即可抬高或压低一段曲线，可撤销。
  性能：光谱计算移到后台线程，拖动滑块不再卡住；画质“自动”在设备跟不上时自动降低计算网格（“更多”里可选高 / 省电）。

0.5.0 新增（第 2 步：目标与数据）
  目标：新增 NGC 2237 玫瑰星云、NGC 7293 上帝之眼（Helix）、NGC 3372 船底座大星云，删去 NGC 7009；
    1× 广域新增“银心 · 蛇夫座调色盘”和“甘姆星云 · 船底座”两个 80° 大场景。
  焦距：深空目标 135–2000 mm 连续可调（口径 f/1.4–f/16 自动夹紧）；面板提示视野中心数据的实际分辨率，
    数据比管子粗时会标出“受巡天数据限制”。
  环顾：未放大时在画面上拖动即转动望远镜，在更大的场景里移动视野（“回到中心”复位）；放大后拖动仍是平移。
  南天数据：SHASSA Hα（瑞利定标）；Helix 细节用 DSS2 底片、[O III] 为按文献总量估计；船底座细节用 VPHAS+ CCD；
    80° 场景加入银河未分辨星光（SHASSA 连续谱，已扣夜天光底）。南天广域没有 [O III]/[S II]。

0.4.1 修订（按实测观感与论文）
  EBI：暗计数改为“阴极暗发射”，默认 1500 /s·mm²（三代 EBI 约 1×10⁻⁷ lx，与论文实测一致），
    暗电子同样经过离子阻挡膜和 MCP 入口；EBI 同时显示 lx 与 lm/cm²。
  噪声：MCP 探测效率（默认 85%）、MCP 输入增强膜开关、三代离子阻挡膜（无/薄/标准）与阴极电压；
    实际 F² 随 MCP 增益和阴极电压变大；参数纸显示噪声因子 N_f，SNR = 1.03·√(S/N_f)。
  实际信噪比：按画面中心的真实速率显示分辨单元与 0.2 mm 光斑的 SNR，以及天光/暗发射各占多少。
  闪烁亮点（雪花）：离子反馈等偶发亮点，比普通闪点亮且更大。
  人眼感知（显示菜单，默认开）：按荧光屏实际亮度模拟暗视觉的分辨极限，只影响显示。
  大气：星点随气流抖动和闪烁；气溶胶放大光污染（SQM 滑块为晴朗值，旁边显示实际值）。
  反射镜：中心遮挡造成的衍射对比度下降进入画面。
  荧光屏：按实测光效 P22 18.85 / P43 13.2 / P45 7.8 lm/W 计算亮度增益。
  光晕：整个圆盘亮度均匀。MTF5 范围 20–120 lp/mm，宽核权重 0–0.6。
  二代（多碱）阴极曲线在 930 nm 截止（原为 1000 nm）。

0.4.0 新增
  管子：光晕（尺寸与占比）、管温（按阴极类型改变暗计数/EBI）、国产三代阴极预设；
    阴极曲线可切换 mA/W 与 QE（默认 mA/W）。
  物镜：折射 / 反射（透过率，或反射率与中心遮挡）、像差弥散；MTF 曲线显示管、物镜+视宁度与系统。
  大气：消光（Paranal 基线 + 可调气溶胶）、视宁度、目标高度角、气辉强度。
  等效参数纸：各滑块下方显示换算出的参数纸数值；右侧底部有完整参数表（A/B 两列，附 L3 样例对照）。
  观察积分默认改为“实时”。

0.3.1 新增
  A|B 对比：工具栏打开后画面左右分成两半同时实时模拟，面板顶部切换“编辑 A / 编辑 B”，
    拖动中间的分界线调整比例；两侧用同一随机序列，参数相同时画面完全一致。
  阴极响应曲线可直接在图上按住拖动改形，“整体倍率”等比例缩放，“重置曲线”恢复预设。
  工具栏“显示”：观察积分时间、显示对比 γ、保存截图 PNG（含参数说明）、复制当前链接。
  当前参数（含 A/B 与编辑过的曲线）自动记在地址栏 # 之后，收藏该地址即可复现。
  暂停时的静帧按“观察积分时间”曝光，观感与实时画面一致。
